# 职业游戏测评

一款基于微信小程序的职业能力测评应用，通过三个小游戏对玩家的手眼协调、空间记忆与精准操控能力进行量化评估，并生成成绩单与评级。

## 功能特性

- 三关能力测评：左右手协调、位置与颜色匹配、精准点击
- 成绩评级（S / A / B / C / D）与星级评分
- 本地保存各关卡历史最佳成绩，支持平均分展示
- Canvas 实时渲染动画效果
- 程序化音效（Web Audio）与震动反馈，支持一键静音
- 横屏全屏沉浸式体验，自定义导航栏

## 关卡介绍

| 关卡 | 名称 | 玩法 | 评测维度 |
| --- | --- | --- | --- |
| 第一关 | 左右手协调 | 双平台同步操控，接住 20 组落物 | 双手协调、反应速度、完成率 |
| 第二关 | 位置与颜色匹配 | 记忆目标布局，拖拽色块完成匹配，共 5 轮递进 | 空间记忆、颜色辨别、准确性 |
| 第三关 | 精准点击 | 30 秒内点击随机出现的环形目标 | 点击精度、命中率、反应时间 |

## 运行方式

1. 使用微信开发者工具导入本项目
2. 填入你的小程序 AppID（或使用测试号）
3. 编译运行，建议在真机上体验以获得最佳性能

项目最低基础库版本：`2.33.0`

## 目录结构

```
├── app.js                 # 全局逻辑，初始化音频
├── app.json               # 全局配置（页面、横屏、自定义导航）
├── app.wxss               # 全局样式
├── utils/
│   ├── audio.js           # 程序化音效与震动封装
│   └── store.js           # 成绩存储、评级与星级计算
└── pages/
    ├── index/             # 首页关卡列表
    ├── level1/            # 第一关 · 左右手协调
    ├── level2/            # 第二关 · 位置与颜色匹配
    ├── level3/            # 第三关 · 精准点击
    └── result/            # 成绩单页面
```

## 评分机制

- 每关完成后根据完成率、准确度、耗时与反应时间等因素计算 0-100 分
- 评级规则：90+ 为 S，80+ 为 A，70+ 为 B，60+ 为 C，其余为 D
- 星级：最高 5 星，对应不同分段

## 技术要点

- 使用 `wx.createWebAudioContext` 合成游戏音效，无需音频资源文件
- 通过 `wx.vibrateShort` 提供触觉反馈
- 第一、三关使用 Canvas 2D（`type="2d"`）实现高性能渲染
- 第二关基于 WXML + movable-view 实现拖拽交互
